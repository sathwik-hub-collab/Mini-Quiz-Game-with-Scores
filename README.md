# Mini Quiz Game with Scores

A simple and interactive console-based quiz application developed using **C++**. The project allows users to answer multiple-choice questions from different knowledge areas, check their answers, and view their final scores.

## About the Project

The **Mini Quiz Game with Scores** is a C++ project developed as part of our academic coursework. The main goal is to create a simple quiz application that makes learning and testing general knowledge more interesting.

Users can select a quiz topic, answer the questions displayed on the console, and receive their results at the end of the quiz. The project also provides practical experience with important C++ programming concepts.

## Features

- Console-based user interface.
- Multiple-choice question format.
- Topic-based quiz selection.
- Automatic answer checking.
- Score calculation and result display.
- Simple and easy-to-use menu.

## How to Run the Project

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/Mini-Quiz-Game-with-Scores.git
```

### 2. Open the Project Folder

```bash
cd Mini-Quiz-Game-with-Scores
```

### 3. Compile the Program

If your main source file is named `main.cpp`, compile it using:

```bash
g++ main.cpp -o quiz
```

### 4. Run the Application

**Windows:**
```bash
quiz.exe
```

**Linux / macOS:**
```bash
./quiz
```

Make sure a C++ compiler, such as GCC, is installed before compiling.
